# Chameleon Frontend

## Development Instructions
- Install node js on your system. Check [here](https://nodejs.org/en/download/) for instructions.
- Confirm that node js is installed by running `node -v` in your terminal.
- Clone this repository.
- Navigate to the root of the repository in your terminal.
- Run `npm install` to install all dependencies.
- Run `npm run dev` to start the development server. The server will be running on port 5173.
- Open `http://localhost:5173` in your browser to view the frontend
